# Road Companion

Navigate Smart. Report Hazards. Travel Safe.

A citizen-powered platform for reporting road hazards and finding safer routes across Gujarat.

## Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Firebase
- Maps: OpenStreetMap + Leaflet
- Hosting: Vercel

## Core Features
- Public hazard map
- Citizen hazard reporting
- Community support
- Report status tracking
- Hazard-aware navigation
- Admin dashboard
